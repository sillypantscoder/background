# background
A strange platformer puzzle game.

## How to install

First, make sure you have Java and Git installed.

- Installing Java:
	1. Go to [https://www.oracle.com/java/technologies/downloads/](https://www.oracle.com/java/technologies/downloads/)
	2. Select your operating system
	3. Click the link next to "x64 Installer" or "x64 DMG Installer"
- Checking if Java is installed:
	1. Open Terminal (on Mac) or Command Prompt (on Windows)
	2. Type `java` and press Enter
	3. If it says "command not found" or "not recognized" or something similar, Java is not installed.
- Installing Git:
	1. Go to [https://git-scm.com/downloads](https://git-scm.com/downloads)
	2. Click on your operating system
- Checking if Git is installed:
	- On Windows, search for the app "Git Bash"
	- On Mac, open Terminal and type `git` and it should not say "command not found"

Then, open Terminal (on Mac) or Git Bash (on Windows) and type `git clone https://github.com/sillypantscoder/background`.

Once it finishes downloading, do `cd background` to enter the game's folder. If you close and reopen your terminal window, you can do `cd background` to get back to this point.

## How to run the game

To run the game, type `python3 compiler.py` (or `py compiler.py` on most Windows devices).

On Windows, you may need to type `java -cp compiled_output com.sillypantscoder.background.Main` to start the game if the previous command fails. (Don't worry, it'll tell you when that happens.)

## How to play

The instructions are mostly explained in-game. You can move with the arrow keys (jump with up arrow or space). Pressing R restarts the level. Pressing Escape exits the level.

The map screen can be navigated by the keyboard. Use the left and right arrow keys to move, and Z or space to select a level. You can enter and exit the settings screen with Escape.
